# NFC — Restaurant Website Concept

A responsive, single-page restaurant website concept with a bold red, black and yellow visual identity, animated hero artwork, menu cards, promotional section and mobile navigation.

## Preview locally

No build tools or package installation are required.

1. Download or clone this repository.
2. Open `index.html` in your browser.

For a local development server, you can use the VS Code **Live Server** extension.

## Publish with GitHub

1. Create a new repository on GitHub (for example, `nfc-restaurant-website`).
2. Upload these project files or push them using Git.
3. To publish it with GitHub Pages, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Customize

- Update text, menu items and links in `index.html`.
- Change colors, layout and responsive styling in `styles.css`.
- Update navigation behavior in `script.js`.
- Replace the demo Unsplash image URLs with your own licensed food photography.

## Notes

This is a front-end demo. The **Order Now** links currently navigate to the menu section; no payment, checkout, ordering backend or restaurant admin system is connected.
